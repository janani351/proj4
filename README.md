# Student Records Manager

A small student directory built with HTML, CSS and vanilla JavaScript.

## Features
- Add student name, roll number and department
- Search by name, roll number or department
- Prevent duplicate roll numbers
- Delete a record
- Persist records with localStorage

## Run
Open `index.html` in a browser.

## Important
This is a frontend learning demo. It stores records in the browser and is not suitable for real student or confidential data.
